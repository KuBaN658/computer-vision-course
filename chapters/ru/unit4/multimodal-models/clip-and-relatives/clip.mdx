# Contrastive Language-Image Pre-training (CLIP)

## Введение

CLIP — это нейронная сеть, умеющая схватывать визуальные концепции через супервизию на естественном языке. Она работает, одновременно обучая текстовый энкодер и энкодер изображений, сосредотачиваясь на задаче предобучения, которая включает сопоставление подписей с соответствующими изображениями. Эта архитектура позволяет CLIP бесшовно адаптироваться к разнообразным бенчмаркам визуальной классификации. Она делает это, просто принимая названия визуальных категорий, которые нужно распознать, демонстрируя способности zero-shot обучения (без примеров класса), сходные с теми, что наблюдаются в моделях GPT-2 и GPT-3.

## Контрастивное предобучение

Дан батч пар изображение–текст: CLIP вычисляет плотную матрицу косинусного сходства между всеми возможными кандидатами (изображение, текст) внутри этого батча. Ключевая идея — максимизировать сходство между правильными парами (показаны синим на рисунке ниже) и минимизировать сходство для неправильных пар (показаны серым на изображении). Для этого оптимизируют симметричную кросс-энтропийную функцию потерь по этим оценкам сходства.

![Контрастивное предобучение CLIP](https://images.openai.com/blob/fbc4f633-9ad4-4dc2-bd94-0b6f1feee22f/overview-a.svg)
_Изображение взято из OpenAI_

Объясняя простыми словами, мы хотим сделать сходство между изображением и его соответствующей подписью как можно выше, а сходство между изображением и другими подписями — маленьким. Ту же логику применяем и к подписи: хотим максимизировать сходство подписи с её соответствующим изображением и минимизировать — со всеми остальными изображениями.

## Текстовый энкодер и энкодер изображений

Дизайн CLIP включает независимые энкодеры для изображений и текста, позволяя гибко выбирать их. Пользователи могут заменить стандартный энкодер изображений вроде Vision Transformer на альтернативы вроде ResNet или выбрать другие текстовые энкодеры, повышая адаптивность и возможности экспериментов. Разумеется, если вы замените один из энкодеров, модель нужно будет обучить заново, потому что распределение эмбеддингов будет другим.

## Сценарии использования
CLIP можно задействовать для разнообразных приложений. Вот некоторые заметные сценарии:

- Zero-shot классификация изображений;
- Поиск по сходству;
- Кондиционирование диффузионных моделей.

## Использование

Для практических приложений обычно используют изображение и заранее заданные классы как вход. Приведённый пример на Python демонстрирует, как использовать библиотеку transformers для запуска CLIP. В этом примере мы хотим zero-shot классифицировать изображение ниже между `dog` и `cat`.

![Фотография кошек](http://images.cocodataset.org/val2017/000000039769.jpg)

```python
from PIL import Image
import requests

from transformers import CLIPProcessor, CLIPModel

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

inputs = processor(
    text=["a photo of a cat", "a photo of a dog"],
    images=image,
    return_tensors="pt",
    padding=True,
)

outputs = model(**inputs)
logits_per_image = outputs.logits_per_image
probs = logits_per_image.softmax(dim=1)
```

После выполнения этого кода мы получили следующие вероятности:
- "a photo of a cat": 99.49%
- "a photo of a dog": 0.51%

## Ограничения

Несмотря на мастерство CLIP в zero-shot классификации, она вряд ли превзойдёт специализированную дообученную модель. Более того, её способности к обобщению несколько ограничены, особенно в сценариях с данными или примерами, не встречавшимися при обучении.
Статья также показывает, что эффективность и смещения (bias) CLIP зависят от выбора категорий, как продемонстрировано в тестах на датасете Fairface. Заметные расхождения были найдены в гендерных и расовых классификациях: точность по полу свыше 96% и расовая точность около 93%.

## Заключение

В заключение, модель CLIP от OpenAI революционизировала мультимодальную область. Что выделяет CLIP — это мастерство в zero-shot обучении, позволяющее классифицировать изображения в категории, на которых она явно не обучалась. Эта замечательная способность обобщаться исходит из инновационного метода обучения, где она учится сопоставлять изображения с текстовыми подписями.
