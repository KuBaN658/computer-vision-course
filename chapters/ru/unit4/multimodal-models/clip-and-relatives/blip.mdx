# Мультимодальная генерация текста (BLIP)
## Введение

После выхода CLIP сообщество ИИ осознало огромный потенциал более крупных датасетов и контрастивного обучения в глубоком обучении. Одно из значительных развитий в этой области — [BLIP (Bootstrapping Language-Image Pre-training)](https://arxiv.org/abs/2201.12086), которое расширяет возможности мультимодальных моделей, включая генерацию текста.

## CapFilt: подписи и фильтрация
Поскольку мультимодальным моделям нужны большие датасеты, их часто приходится собирать из интернета, используя пары изображение и альтернативный текст (alt-text). Однако alt-тексты часто неточно описывают визуальное содержание изображений, делая их шумным сигналом, субоптимальным для обучения выравнивания зрения и языка. Поэтому статья BLIP ввела механизм подписей и фильтрации (CapFilt). Он состоит из модели глубокого обучения, которая отфильтровывает шумные пары, и другой модели, которая создаёт подписи к изображениям. Обе эти модели сначала дообучают на датасете с человеческой разметкой. Авторы обнаружили, что очистка датасета с помощью CapFilt даёт превосходящее качество по сравнению с использованием только веб-датасета. Дальнейшие детали этого процесса можно найти в [статье BLIP](https://arxiv.org/abs/2201.12086).

## Архитектура и обучение BLIP
Архитектура BLIP сочетает визуальный энкодер и Multimodal Mixture of Encoder-Decoder (MED), позволяя универсальную обработку и визуальных, и текстовых данных. Её структура показана на рисунке ниже, где блоки одного цвета разделяют параметры:

- **Vision Transformer (ViT):** Это обычный vision transformer с self-attention, блоками feed-forward и токеном [CLS] для представления эмбеддинга.
- **Унимодальный текстовый энкодер:** Напоминая архитектуру BERT, он использует токен [CLS] для эмбеддинга и применяет контрастивную функцию потерь, как CLIP, для выравнивания представлений изображения и текста.
- **Текстовый энкодер, заземлённый в изображении:** Он заменяет токен [CLS] токеном [Encode]. Слои cross-attention позволяют интегрировать эмбеддинги изображения и текста, создавая мультимодальное представление. Он применяет линейный слой, чтобы оценивать согласованность пар изображение–текст.
- **Текстовый декодер, заземлённый в изображении:** Заменяя двунаправленный self-attention каузальным self-attention, этот декодер обучается через кросс-энтропийную функцию потерь авторегрессионным образом для задач вроде генерации подписей или ответов на визуальные вопросы.

Архитектура BLIP интегрирует визуальный энкодер с мультимодальной смесью компонентов энкодер–декодер, позволяя продвинутую обработку текста и изображений. Этот дизайн позволяет ей умело справляться с разнообразными задачами: от выравнивания пар изображение–текст до генерации подписей и ответов на визуальные вопросы.

## Пример сценария: BLIP-2
После успеха BLIP её создатель Salesforce представил BLIP-2 — улучшенную итерацию. Достижения и возможности BLIP-2 подробно описаны в [статье BLIP-2](https://arxiv.org/abs/2301.12597) и в [документации Hugging Face](https://huggingface.co/docs/transformers/model_doc/blip-2). Здесь мы используем BLIP-2 для visual question answering.

```python
from PIL import Image
import requests
from transformers import Blip2Processor, Blip2ForConditionalGeneration
import torch

device = "cuda" if torch.cuda.is_available() else "cpu"

processor = Blip2Processor.from_pretrained("Salesforce/blip2-opt-2.7b")
model = Blip2ForConditionalGeneration.from_pretrained(
    "Salesforce/blip2-opt-2.7b", torch_dtype=torch.float16
)
model.to(device)
url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

prompt = "Question: How many remotes are there? Answer:"
inputs = processor(images=image, text=prompt, return_tensors="pt").to(
    device, torch.float16
)
outputs = model.generate(**inputs)
text = processor.tokenizer.batch_decode(outputs, skip_special_tokens=True)
print(text)
```
Этот фрагмент кода иллюстрирует применение BLIP-2 для visual question answering. Экспериментируйте с более сложными запросами или изучите эту функциональность дальше с помощью предоставленного приложения Gradio:

## Заключение

BLIP отмечает значительную веху в мультимодальной генерации текста, опираясь на сильные стороны CLIP, чтобы создать устойчивую модель. Она подчёркивает важность качества датасета над количеством, способствуя развитию мультимодального обучения. Для подробностей обратитесь к [статье BLIP](https://arxiv.org/abs/2201.12086), [статье BLIP-2](https://arxiv.org/abs/2301.12597) и документации Hugging Face по [BLIP](https://huggingface.co/docs/transformers/model_doc/blip) и [BLIP-2](https://huggingface.co/docs/transformers/model_doc/blip-2).
