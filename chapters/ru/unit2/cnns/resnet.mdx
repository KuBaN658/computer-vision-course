# ResNet (Residual Network)




Предполагалось, что нейронные сети с большим числом слоёв эффективнее, потому что добавление слоёв улучшает качество модели.

По мере того как сети становились глубже, извлечённые признаки могли ещё больше обогащаться, как видно на примере VGG16 и VGG19.

Возник вопрос: «Так же ли легко обучать сети, как просто складывать больше слоёв?»
Препятствие к ответу на этот вопрос — проблема затухания градиента — было снято нормализованными инициализациями и промежуточными слоями нормализации.

Однако появилась новая проблема: проблема деградации. По мере того как нейронные сети становились глубже, точность насыщалась и быстро падала. Эксперимент, сравнивающий мелкие и глубокие обычные сети, показал, что более глубокие модели имеют более высокие ошибки обучения и теста, что указывает на фундаментальную трудность эффективного обучения более глубоких архитектур. Эта деградация была не из-за переобучения, а потому что ошибка обучения росла, когда сеть становилась глубже. Добавленные слои не аппроксимировали тождественную функцию.

<img src="https://i.sstatic.net/xDLez.jpg" alt="Ошибка деградации" width="512" height="512">


Остаточные соединения (residual) ResNet раскрыли потенциал экстремальной глубины, поднимая точность вверх по сравнению с предыдущими архитектурами.



## Архитектура ResNet

- Остаточный блок. Источник: статья ResNet
![остаточный блок](https://huggingface.co/datasets/hf-vision/course-assets/blob/main/ResnetBlock.png)

ResNet вводят концепцию residual learning, которая позволяет сети выучивать остатки (то есть разницу между выученным представлением и входом), вместо того чтобы пытаться напрямую отображать входы в выходы. Это достигается через skip connections (или shortcut connections).


Давайте разберём это:

#### 1. Базовый строительный блок: остаточный блок

В типичном слое нейронной сети мы стремимся выучить отображение F(x), где x — вход, а F — преобразование, которое применяет сеть. Без residual learning преобразование на слое таково: y = F(x). В ResNet вместо того, чтобы выучивать F(x) напрямую, сеть спроектирована так, чтобы выучивать остаток R(x), где: R(x) = F(x) − x. Таким образом, преобразование в остаточном блоке записывается как: y = F(x) + x.

Здесь x — вход остаточного блока, а F(x) — выход сложенных слоёв блока (обычно свёртки, пакетная нормализация (batch normalization) и ReLU). Тождественное отображение x напрямую добавляется к выходу F(x) (через skip connection). Таким образом, блок выучивает остаток R(x) = F(x), а финальный выход — F(x) + x. Эту остаточную функцию легче оптимизировать по сравнению с исходным отображением. Если оптимальное преобразование близко к тождественному (то есть преобразование не нужно), сеть может легко задать F(x) ≈ 0, чтобы пропустить вход как есть.



* Строительный блок ResNet можно увидеть на картинке, источник — статья ResNet.

![строительный блок resnet](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/ResnetBlock.png)


#### 2. Обучение остатков и поток градиента

Главная причина, почему сети ResNet хорошо работают для очень глубоких сетей, — улучшенный поток градиента при обратном распространении. Давайте математически разберём обратный проход. Допустим, у вас есть остаточный блок y = F(x) + x. При вычислении градиентов по цепному правилу мы считаем производную потери 𝐿 по входу x. Для стандартного блока (без остатков) градиент равен:

`∂x/∂L = ∂F(x)/∂L * ∂F(x)/∂x`

Однако для остаточного блока, где y = F(x) + x, градиент становится:

`∂L/∂x = ∂L/∂F(x) * ∂F(x)/∂x + ∂L/∂F(x) ⋅1`

Заметьте, что теперь в вычислении градиента есть дополнительный член 1. Это значит, что градиент на каждом слое имеет прямой путь назад к более ранним слоям, улучшая поток градиента и снижая шанс затухания градиентов. Градиенты легче текут через сеть, позволяя обучать более глубокие сети без деградации.

#### 3. Почему теперь возможны более глубокие сети:

ResNet сделали возможным обучать сети с сотнями или даже тысячами слоёв. Вот почему более глубокие сети выигрывают от этого:

* Identity Shortcut Connections: Shortcut-соединения выполняют тождественное отображение, и их выход добавляется к выходу сложенных слоёв. Identity shortcut connections не добавляют ни лишних параметров, ни
вычислительной сложности: эти соединения обходят слои, создавая прямые пути для потока информации, и позволяют нейронным сетям выучивать остаточную функцию (F).
* Лучший поток градиента: Как объяснялось ранее, остатки помогают градиентам лучше распространяться при обратном распространении, решая проблему затухания градиента в очень глубоких сетях.
* Легче оптимизировать: Выучивая остатки, сеть по сути разбивает процесс обучения на более лёгкие, пошаговые шаги. Сети легче выучить остаток R(x) = F(x) − x, чем выучить F(x) напрямую, особенно в очень глубоких сетях.


### Кратко:

Можно заключить, что сеть ResNet -> обычная сеть + shortcuts!

Для операций  \(F(x) + x\)  \(F(x)\) и \(x\) должны иметь одинаковые размерности.
ResNet использует две техники, чтобы этого добиться:

- Zero-padding shortcuts, которые добавляют каналы с нулевыми значениями, сохраняя размерности без введения дополнительных параметров для обучения.
- Projection shortcuts, которые используют свёртки 1x1, чтобы подстраивать размерности при необходимости, вводя некоторые дополнительные обучаемые параметры.

В более глубоких архитектурах ResNet, таких как ResNet 50, 101 и 152, применяют специализированный «bottleneck building block», чтобы управлять сложностью параметров и сохранять эффективность, позволяя ещё более глубокое обучение.

## Код ResNet


### Глубокие остаточные сети, предобученные на ImageNet
Ниже вы можете увидеть, как загрузить предобученный ResNet с головой классификации изображений с помощью библиотеки transformers.
```python
from transformers import ResNetForImageClassification

model = ResNetForImageClassification.from_pretrained("microsoft/resnet-50")

model.eval()
```
Все предобученные модели ожидают входные изображения, нормализованные одинаково, то есть мини-батчи 3-канальных RGB-изображений формы (3 x H x W), где H и W ожидаются не меньше 224. Изображения нужно загрузить в диапазон [0, 1], а затем нормализовать, используя mean = [0.485, 0.456, 0.406] и std = [0.229, 0.224, 0.225].


Ниже пример запуска. Этот пример доступен в [документации Hugging Face](https://huggingface.co/docs/transformers/v4.18.0/en/model_doc/resnet).

```python
from transformers import AutoFeatureExtractor, ResNetForImageClassification
import torch
from datasets import load_dataset

dataset = load_dataset("huggingface/cats-image")
image = dataset["test"]["image"][0]

feature_extractor = AutoFeatureExtractor.from_pretrained("microsoft/resnet-50")
model = ResNetForImageClassification.from_pretrained("microsoft/resnet-50")

inputs = feature_extractor(image, return_tensors="pt")

with torch.no_grad():
    logits = model(**inputs).logits

# model predicts one of the 1000 ImageNet classes
predicted_label = logits.argmax(-1).item()
print(model.config.id2label[predicted_label])
```
