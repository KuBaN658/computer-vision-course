## Введение

![Пример детекции объектов](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/object_detection_wiki.png)

Детекция объектов — задача компьютерного зрения, которая состоит в идентификации и локализации объектов на изображении или в видео. Она включает два основных шага:

- Во-первых, распознать типы присутствующих объектов (например, машины, люди или животные).
- Во-вторых, определить их точные положения, нарисовав вокруг них ограничивающие прямоугольники.

Эти модели обычно получают изображения (статические или кадры из видео) как входы, причём на каждом изображении присутствует несколько объектов. Например, рассмотрим изображение, содержащее несколько объектов: машины, люди, велосипеды и так далее. Обработав вход, эти модели выдают набор чисел, которые передают следующую информацию:

- Положение объекта (координаты XY ограничивающего прямоугольника).
- Класс объекта.

Вокруг детекции объектов много применений. Один из самых значимых примеров — область автономного вождения, где детекцию объектов используют, чтобы детектировать разные объекты (пешеходов, дорожные знаки, светофоры и т. д.) вокруг автомобиля, которые становятся одним из входов для принятия решений.

Чтобы глубже понять внутреннее устройство детекции объектов, загляните в нашу [отдельную главу](https://huggingface.co/learn/computer-vision-course/unit6/basic-cv-tasks/object_detection) о детекции объектов 🤗.

### Зачем дообучать модели в детекции объектов 🤔

Стоит ли строить новую модель или изменять существующую? Это отличный вопрос. Обучение модели детекции объектов с нуля означает:

- Снова и снова делать уже проделанные исследования.
- Писать повторяющийся код модели, обучать её и поддерживать разные репозитории для разных сценариев.
- Много экспериментов и траты ресурсов.

Вместо всего этого возьмите хорошо работающую предобученную модель (модель, которая отлично распознаёт общие признаки) и подстройте или перенастройте её веса (или часть её весов), чтобы адаптировать её под ваш сценарий. Мы полагаем или предполагаем, что предобученная модель уже достаточно научилась извлекать значимые признаки внутри изображения, чтобы локализовать и классифицировать объекты. Поэтому если вводят новые объекты, ту же модель можно обучить в течение небольшого времени и с небольшими вычислениями, чтобы она начала детектировать эти новые объекты с помощью уже выученных и новых признаков.

Теперь, когда мы знаем, что содержит точка данных, начнём с отрисовки этого образца. Сначала нарисуем изображение, а затем также нарисуем соответствующий ограничивающий прямоугольник.

Вот что мы собираемся сделать:

1. Получить изображение и его высоту и ширину.
2. Создать объект draw, который может легко рисовать текст и линии на изображении.
3. Получить словарь annotations из образца.
4. Пройти по нему.
5. Для каждого получить координаты ограничивающего прямоугольника: x (где ограничивающий прямоугольник начинается горизонтально), y (где ограничивающий прямоугольник начинается вертикально), w (ширина ограничивающего прямоугольника), h (высота ограничивающего прямоугольника).
6. Теперь, если измерения ограничивающего прямоугольника нормализованы, масштабировать их, иначе оставить как есть.
7. И наконец нарисовать прямоугольник и текст категории класса.

```python 
import numpy as np
from PIL import Image, ImageDraw


def draw_image_from_idx(dataset, idx):
    sample = dataset[idx]
    image = sample["image"]
    annotations = sample["objects"]
    draw = ImageDraw.Draw(image)
    width, height = sample["width"], sample["height"]

    for i in range(len(annotations["id"])):
        box = annotations["bbox"][i]
        class_idx = annotations["id"][i]
        x, y, w, h = tuple(box)
        if max(box) > 1.0:
            x1, y1 = int(x), int(y)
            x2, y2 = int(x + w), int(y + h)
        else:
            x1 = int(x * width)
            y1 = int(y * height)
            x2 = int((x + w) * width)
            y2 = int((y + h) * height)
        draw.rectangle((x1, y1, x2, y2), outline="red", width=1)
        draw.text((x1, y1), annotations["category"][i], fill="white")
    return image


draw_image_from_idx(dataset=train_dataset, idx=10)
```

## Предобработка датасета

Перед передачей изображений в `image_processor` давайте также применим разные типы аугментаций к изображениям вместе с соответствующими ограничивающими прямоугольниками.

Простыми словами, аугментации — это набор случайных преобразований вроде поворотов, изменения размера и т. д. Их применяют, чтобы получить больше образцов и сделать модель зрения более устойчивой к разным условиям изображения. Мы используем библиотеку [albumentations](https://github.com/albumentations-team/albumentations), чтобы этого достичь. Она позволяет создавать случайные преобразования изображений, чтобы размер выборки для обучения увеличился.

```python
import albumentations
import numpy as np
import torch

transform = albumentations.Compose(
    [
        albumentations.Resize(480, 480),
        albumentations.HorizontalFlip(p=1.0),
        albumentations.RandomBrightnessContrast(p=1.0),
    ],
    bbox_params=albumentations.BboxParams(format="coco", label_fields=["category"]),
)
```

После инициализации всех преобразований нужно сделать функцию, которая форматирует аннотации и возвращает список аннотаций в очень конкретном формате.

Это потому, что `image_processor` ожидает аннотации в следующем формате: `{'image_id': int, 'annotations': List[Dict]}`, где каждый словарь — аннотация объекта COCO.

```python
def formatted_anns(image_id, category, area, bbox):
    annotations = []
    for i in range(0, len(category)):
        new_ann = {
            "image_id": image_id,
            "category_id": category[i],
            "isCrowd": 0,
            "area": area[i],
            "bbox": list(bbox[i]),
        }
        annotations.append(new_ann)

    return annotations
```

Наконец, мы объединяем преобразования изображения и аннотаций, чтобы выполнять преобразования по всему батчу датасета.

Вот финальный код для этого:

```python
# transforming a batch


def transform_aug_ann(examples):
    image_ids = examples["image_id"]
    images, bboxes, area, categories = [], [], [], []
    for image, objects in zip(examples["image"], examples["objects"]):
        image = np.array(image.convert("RGB"))[:, :, ::-1]
        out = transform(image=image, bboxes=objects["bbox"], category=objects["id"])

        area.append(objects["area"])
        images.append(out["image"])
        bboxes.append(out["bboxes"])
        categories.append(out["category"])

    targets = [
        {"image_id": id_, "annotations": formatted_anns(id_, cat_, ar_, box_)}
        for id_, cat_, ar_, box_ in zip(image_ids, categories, area, bboxes)
    ]

    return image_processor(images=images, annotations=targets, return_tensors="pt")
```

Наконец, всё, что нужно сделать, — применить эту функцию предобработки ко всему датасету. Это можно сделать с помощью метода Hugging Face 🤗 [Datasets with transform](https://huggingface.co/docs/datasets/v2.15.0/en/package_reference/main_classes#datasets.Dataset.with_transform).

Мы почти у цели 🚀. Как последний шаг предобработки нужно написать собственный `collate_fn`. Что такое `collate_fn`?

`collate_fn` отвечает за то, чтобы взять список образцов из датасета и преобразовать их в батч, подходящий для входного формата модели.

В общем `DataCollator` обычно выполняет такие задачи, как паддинг, усечение и т. д. В собственной функции collate мы часто определяем, что и как хотим группировать данные в батчи, или просто как представлять каждый батч.

Data collator в основном собирает данные вместе, а затем предобрабатывает их. Давайте сделаем нашу функцию collate.

```python
def collate_fn(batch):
    pixel_values = [item["pixel_values"] for item in batch]
    encoding = image_processor.pad(pixel_values, return_tensors="pt")
    labels = [item["labels"] for item in batch]
    batch = {}
    batch["pixel_values"] = encoding["pixel_values"]
    batch["pixel_mask"] = encoding["pixel_mask"]
    batch["labels"] = labels
    return batch
```

## Обучение модели DETR

Итак, вся тяжёлая работа уже сделана. Теперь осталось собрать части пазла одну за другой. Поехали!

Процедура обучения включает следующие шаги:

1. Загрузка базовой (предобученной) модели с [AutoModelForObjectDetection](https://huggingface.co/docs/transformers/v4.36.0/en/model_doc/auto#transformers.AutoModelForObjectDetection), используя тот же чекпоинт, что и при предобработке.

2. Определение всех гиперпараметров и дополнительных аргументов внутри [TrainingArguments](https://huggingface.co/docs/transformers/v4.36.0/en/main_classes/trainer#transformers.TrainingArguments).

3. Передача аргументов обучения внутрь [Hugging Face Trainer](https://huggingface.co/docs/transformers/v4.36.0/en/main_classes/trainer#transformers.Trainer) вместе с моделью, датасетом и изображением.

4. Вызов метода `train()` и дообучение модели.

> Загружая модель из того же чекпоинта, который вы использовали для предобработки, не забудьте передать отображения `label2id` и `id2label`, которые вы создали ранее из метаданных датасета. Кроме того, мы указываем `ignore_mismatched_sizes=True`, чтобы заменить существующую голову классификации новой.

```python
from transformers import AutoModelForObjectDetection

id2label = {0: "head", 1: "helmet", 2: "person"}
label2id = {v: k for k, v in id2label.items()}


model = AutoModelForObjectDetection.from_pretrained(
    checkpoint,
    id2label=id2label,
    label2id=label2id,
    ignore_mismatched_sizes=True,
)
```

Теперь сделаем очень простую функцию, чтобы нарисовать результаты на нашем изображении. Из results мы получаем score, label и соответствующие координаты ограничивающих прямоугольников, которые используем, чтобы рисовать на изображении.

```python
def plot_results(image, results, threshold=0.7):
    image = Image.fromarray(np.uint8(image))
    draw = ImageDraw.Draw(image)
    for result in results:
        score = result["score"]
        label = result["label"]
        box = list(result["box"].values())
        if score > threshold:
            x, y, x2, y2 = tuple(box)
            draw.rectangle((x, y, x2, y2), outline="red", width=1)
            draw.text((x, y), label, fill="white")
            draw.text(
                (x + 0.5, y - 0.5),
                text=str(score),
                fill="green" if score > 0.7 else "red",
            )
    return image
```

И наконец используем эту функцию для того же тестового изображения.


```

plot_results(image, results)
```

![отрисовка тестового выходного изображения](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/test_output_for_od.png)

Теперь соберём всё вместе в простую функцию.

```python
def predict(image, pipeline, threshold=0.7):
    results = pipeline(image)
    return plot_results(image, results, threshold)
```

```python 
from tqdm.auto import tqdm


def plot_images(dataset, indices):
    """
    Plot images and their annotations.
    """
    num_rows = len(indices) // 3
    num_cols = 3
    fig, axes = plt.subplots(num_rows, num_cols, figsize=(15, 10))

    for i, idx in tqdm(enumerate(indices), total=len(indices)):
        row = i // num_cols
        col = i % num_cols

        # Draw image
        image = predict(dataset[idx]["image"], obj_detector)

        # Display image on the corresponding subplot
        axes[row, col].imshow(image)
        axes[row, col].axis("off")

    plt.tight_layout()
    plt.show()


plot_images(test_dataset, range(6))
```
