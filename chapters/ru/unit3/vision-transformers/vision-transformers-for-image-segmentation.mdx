## CNN против трансформеров для сегментации

До появления трансформеров зрения CNN (свёрточные нейронные сети) были основным выбором для сегментации изображений. Модели вроде [U-Net](https://arxiv.org/abs/1505.04597) и [Mask R-CNN](https://arxiv.org/abs/1703.06870) захватывали детали, нужные, чтобы различать разные объекты на изображении, и стали передовыми для задач сегментации.

Несмотря на отличные результаты за последнее десятилетие, у моделей на основе CNN есть ограничения, которые трансформеры стремятся решить:

- **Пространственные ограничения**: CNN обучают локальные паттерны через небольшие рецептивные поля. Такой локальный фокус затрудняет «связывание» признаков, которые находятся далеко друг от друга, но связаны внутри изображения, и это влияет на способность точно сегментировать сложные сцены/объекты. В отличие от CNN, ViT спроектированы так, чтобы захватывать глобальные зависимости внутри изображения, опираясь на механизм внимания. Это значит, что модели на основе ViT рассматривают всё изображение сразу, что позволяет им понимать сложные связи между удалёнными частями изображения. Для сегментации такая глобальная перспектива может привести к более точному оконтуриванию объектов.
- **Компоненты, специфичные для задачи**: Методы вроде Mask R-CNN включают вручную спроектированные компоненты (например, non-maximum suppression, пространственные якоря), чтобы закодировать априорные знания о задачах сегментации. Эти компоненты добавляют сложность и требуют ручной настройки. Напротив, методы сегментации на основе ViT упрощают процесс сегментации, устраняя необходимость во вручную спроектированных компонентах и делая их проще оптимизировать.
- **Специализация под задачу сегментации**: Модели сегментации на основе CNN подходят к семантической, экземплярной и паноптической сегментации по отдельности, что приводит к специализированным архитектурам для каждой задачи и отдельным исследовательским усилиям по каждой. Недавние модели на основе ViT вроде [MaskFormer](https://arxiv.org/abs/2107.06278), [SegFormer](https://arxiv.org/abs/2105.15203) или [SAM](https://arxiv.org/abs/2304.02643) дают единый подход к семантической, экземплярной и паноптической сегментации в рамках одной архитектуры.

## В центре внимания MaskFormer: иллюстрация ViT для сегментации изображений

MaskFormer ([статья](https://arxiv.org/abs/2107.06278), [документация Hugging Face transformers](https://huggingface.co/docs/transformers/en/model_doc/maskformer)), представленный в статье "MaskFormer: Per-Pixel Classification is Not All You Need for Semantic Segmentation", — это модель, которая предсказывает маски сегментации для каждого класса, присутствующего на изображении, объединяя семантическую и экземплярную сегментацию в одной архитектуре.

### Архитектура MaskFormer

Рисунок ниже показывает схему архитектуры, взятую из статьи.

  width="600"
  src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/maskformer_architecture.png"

Архитектура состоит из трёх компонентов:

**Пиксельный модуль**: Использует backbone для извлечения признаков изображения и пиксельный декодер для генерации эмбеддингов на каждый пиксель.

**Модуль трансформера**: Применяет стандартный декодер трансформера, чтобы вычислить эмбеддинги на каждый сегмент из признаков изображения и обучаемых позиционных эмбеддингов (запросов), кодируя глобальную информацию о каждом сегменте.

**Модуль сегментации**: Генерирует предсказания вероятностей классов и эмбеддинги масок для каждого сегмента с помощью линейного классификатора и многослойного перцептрона (MLP) соответственно. Эмбеддинги масок используются вместе с эмбеддингами на каждый пиксель, чтобы предсказать бинарные маски для каждого сегмента.

Модель обучают с бинарной потерей по маске — той же, что и у [DETR](https://huggingface.co/learn/computer-vision-course/unit3/vision-transformers/detr), — и кросс-энтропийной классификационной потерей на каждый предсказанный сегмент.

### Пример инференса паноптической сегментации с Hugging Face Transformers

Паноптическая сегментация — это задача разметить каждый пиксель изображения его категорией и идентифицировать отдельные объекты внутри этих категорий, сочетая семантическую и экземплярную сегментацию.

```python
from transformers import pipeline
from PIL import Image
import requests

segmentation = pipeline("image-segmentation", "facebook/maskformer-swin-base-coco")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

results = segmentation(inputs=image, subtask="panoptic")
results
```

## Дообучение моделей сегментации на основе трансформеров зрения

При множестве доступных предобученных моделей сегментации трансферное обучение и дообучение обычно используют, чтобы адаптировать эти модели к конкретным сценариям, особенно потому, что модели сегментации на основе трансформеров, вроде MaskFormer, прожорливы к данным и их трудно обучать с нуля.
Эти техники используют предобученные представления, чтобы эффективно адаптировать модели к новым данным. Обычно для MaskFormer backbone, пиксельный декодер и декодер трансформера держат замороженными, чтобы использовать их выученные общие признаки, а модуль трансформера дообучают, чтобы адаптировать его способности предсказывать классы и генерировать маски к новым задачам сегментации.

[Этот ноутбук](https://colab.research.google.com/github/huggingface/computer-vision-course/blob/main/notebooks/Unit%203%20-%20Vision%20Transformers/transfer-learning-segmentation.ipynb) проведёт вас через туториал по трансферному обучению для сегментации изображений с использованием MaskFormer.
