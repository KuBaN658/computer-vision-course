# Генерация синтетических данных с помощью 3D-рендерера

Когда мы создаём компьютерные изображения для использования в качестве синтетических обучающих данных, в идеале хотим, чтобы они выглядели как можно реалистичнее.
Physically Based Renderers (PBR), такие как [Blender Cycles](https://www.blender.org)
или [Unity](https://unity.com), помогают создавать изображения, которые выглядят сверхреалистично — так, как вещи выглядят и ощущаются в реальном мире.

Представьте, что вы создаёте изображение блестящего яблока. Когда вы его раскрашиваете, хотите, чтобы оно выглядело реалистично, верно?
Вот тут и появляется то, что называют PBR.

![яблоко](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/apple.jpg)

Хорошо, давайте разберём по частям:

_Цвета и свет:_

- Когда свет падает на объекты, он взаимодействует с ними по-разному. PBR пытается разобрать и смоделировать это взаимодействие.
- Подумайте, как свет попадает на яблоко. Одни части могут быть ярче там, куда свет падает напрямую, а другие — темнее
  там, где свет заблокирован или доходит слабее.

_Материалы:_

- Разные материалы реагируют на свет по-разному. Например, блестящая металлическая поверхность отражает свет сильнее, чем мягкая матовая ткань.
- PBR учитывает материал объекта: если вы рендерите металлическую вазу, она будет отражать свет иначе, чем пушистый плюшевый медведь.

_Текстуры:_

- PBR использует текстуры, чтобы добавить детали вроде неровностей, царапин или крошечных борозд на поверхности объектов. Это делает вещи более реальными, потому что в реальном мире почти ничего не бывает идеально гладким.

_Реализм:_

- PBR стремится сделать изображение как можно ближе к реальной жизни. Для этого учитывается, как свет ведёт себя в действительности, как разные материалы взаимодействуют со светом и как на поверхностях есть мелкие несовершенства.

_Слои света:_

- Представьте, что вы смотрите на стакан воды. PBR попытается смоделировать, как свет проходит сквозь воду и как это может искажать то, что вы видите.
- Он учитывает, как несколько слоёв света взаимодействуют с разными частями объекта, делая отрендеренное изображение более реалистичным.

PBR также упрощает рабочий процесс. Вместо того чтобы вручную крутить множество параметров, чтобы получить нужный вид,
можно использовать набор стандартизированных материалов и моделей освещения.
Это делает процесс более интуитивным и удобным.

Теперь подумайте об обучении моделей ИИ, вроде тех, что используют в компьютерном зрении.
Если вы учите компьютер распознавать объекты на изображениях, полезно иметь разнообразный набор
изображений, которые близко имитируют реальные сценарии. PBR помогает генерировать синтетические данные, которые выглядят настолько реально, что их можно эффективно
использовать для обучения моделей компьютерного зрения.

Есть несколько 3D-движков рендеринга, которые можно использовать для PBR, включая [Blender Cycles](https://www.blender.org)
или [Unity](https://unity.com). Мы сосредоточимся на Blender, потому что он с открытым исходным кодом и вокруг него много материалов.

## Blender

Blender — мощное 3D-программное обеспечение с открытым исходным кодом, которое используют для создания анимационных фильмов, визуальных эффектов, искусства, 3D-игр и многого другого.
Оно охватывает широкий набор возможностей и поэтому остаётся универсальным инструментом для художников, аниматоров и разработчиков.
Начнём с простого примера: отрендерим синтетическое изображение слона.

Вот основные шаги:

- Создать модель слона. Показанная ниже была сделана в приложении [Metascan](https://metascan.ai) с помощью фотограмметрии.
  Фотограмметрия — способ превратить обычные фотографии в 3D-модель. Это как снять кучу фотографий игрушки с разных ракурсов
  и затем по этим снимкам собрать компьютерную версию.
- Создать фон — это был многошаговый процесс. См. [здесь](https://github.com/kfahn22/Synthetic-Data-Creation-in-Blender/tree/main/BACKGROUND)
  более подробное объяснение.
- Настроить освещение и положения камеры.
- Зафиксировать положение и поворот слона так, чтобы он помещался в кадр (или в поле зрения камеры).

Вот изображение слона, сгенерированное в Blender:

![изображение слона](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/synthetic-data-creation-PBR/rendered_elephant.png)

Оно не полностью фотореалистично, но, вероятно, достаточно близко, чтобы обучить модель для мониторинга популяций слонов. Конечно, для этого
нужно создать большой датасет синтетических изображений слонов! Можно использовать Python-окружение Blender
[bpy](https://docs.blender.org/api/current/info_advanced_blender_as_bpy.html), чтобы рендерить
большое число изображений со случайными положением и поворотом слона.
Можно также использовать скрипт, чтобы помочь с сегментацией, глубиной, нормалями и оценкой позы.

Отлично! С чего начать?

К сожалению, у Blender довольно крутая кривая обучения. Ни один из шагов сам по себе не слишком сложен,
но разве не было бы здорово отрендерить датасет, не разбираясь во всём этом?
К счастью, есть библиотека BlenderProc, в которой уже есть все скрипты, нужные для рендеринга реалистичных синтетических данных
и разметки, и она построена поверх Blender.

## BlenderProc

Пайплайн BlenderProc был представлен в [BlenderProc](https://arxiv.org/abs/1911.01911), Denninger, et. al., и это модульный пайплайн, построенный поверх [Blender](https://www.blender.org/).
Его можно использовать для генерации изображений в самых разных задачах, включая сегментацию, глубину, нормали и оценку позы.

Он специально создан, чтобы помогать в генерации реалистичных изображений для обучения свёрточных нейронных сетей.  
 У него есть следующие свойства, которые делают его отличным выбором для генерации синтетических данных:

- Процедурная генерация: позволяет автоматически создавать сложные 3D-сцены с вариациями с помощью процедурных техник.
- Симуляция: поддерживает интеграцию симуляций, включая физические, чтобы повысить реализм.
- Генерация большого масштаба: спроектирован эффективно обрабатывать генерацию сцен большого масштаба, что подходит для разнообразных применений.
- Автоматизация и масштабируемость:
  - Скрипты: позволяют автоматизировать процесс генерации, используя Python-скрипты, чтобы подогнать BlenderProc под конкретные нужды и настроить параметры.
  - Параллельная обработка: поддерживает параллельную обработку для масштабируемости, что делает эффективной генерацию большого числа сцен.

BlenderProc можно установить через pip:

```bash
pip install blenderProc
```

Либо можно клонировать официальный [репозиторий BlenderProc](https://github.com/DLR-RM/BlenderProc) с GitHub с помощью Git:

```bash
git clone https://github.com/DLR-RM/BlenderProc
```

BlenderProc нужно запускать внутри Python-окружения Blender (bpy), потому что только так можно получить доступ к Blender API.

```bash
blenderproc run <your_python_script>
```

Можно открыть этот ноутбук, чтобы попробовать BlenderProc в Google Colab: он демонстрирует базовые примеры, приведённые [здесь](https://github.com/DLR-RM/BlenderProc/tree/main/examples/basics).
