# Введение

## Что такое облако точек?

Облако точек — это набор отдельных точек, каждая из которых представляет собой выборку поверхности в трёхмерном пространстве и задаётся координатами [x, y, z]. Помимо пространственных координат эти точки часто несут дополнительные атрибуты: нормали, RGB-цвет, альбедо и Bidirectional Reflectance Distribution Function (BRDF).

Альбедо — мера того, сколько света отражает поверхность. По сути это отношение отражённого света к падающему свету, который попадает на поверхность. Проще говоря, оно описывает, какая доля входящего света отскакивает обратно. Высокое альбедо означает поверхность, которая отражает много света, например снег, а низкое — поверхность, которая поглощает больше света, например асфальт.

BRDF — функция, которая описывает, как свет рассеивается или отражается на непрозрачной поверхности. Она детализирует способ отражения света в точке пересечения на поверхности с учётом направления входящего света и исходящего направления. Она даёт математическое описание отражающих свойств поверхности, включая такие факторы, как глянцевость, шероховатость и распределение отражённого света по разным углам.
Эти атрибуты играют ключевую роль в разных применениях: моделировании, рендеринге и понимании сцен.

Хотя концепция данных облака точек не нова и уже много лет важна в таких областях, как графика и физическая симуляция, её значимость заметно выросла благодаря двум ключевым тенденциям.
Во-первых, широкая доступность недорогих и удобных устройств захвата облаков точек существенно повысила доступность.

Дополненная реальность и автономные транспортные средства ещё сильнее подчеркнули их актуальность в сегодняшнем технологическом ландшафте.

**Теперь, когда мы знаем, что такое облако точек, что с ними можно делать?**

3D-точечные данные в основном используют для возможностей автономного вождения, но теперь и другие модели ИИ на основе компьютерного зрения — дроны и роботы — тоже используют LiDAR для лучшего визуального восприятия. LiDAR — процесс дистанционного зондирования, который собирает измерения, используемые для создания 3D-моделей и карт объектов и окружения. Используя ультрафиолетовый, видимый или ближний инфракрасный свет, LiDAR оценивает пространственные отношения и формы, измеряя время, за которое сигналы отражаются от объектов и возвращаются к сканеру.

## Генерация и представление данных

Мы будем использовать Python-библиотеку [point-cloud-utils](https://github.com/fwilliams/point-cloud-utils) и [open-3d](https://github.com/isl-org/Open3D), которые можно установить так:

```bash
pip install point-cloud-utils
```

Мы также будем использовать Python-библиотеку open-3d, которую можно установить так:

```bash
pip install open3d
```

ИЛИ меньшую версию только для CPU:

```bash
pip install open3d-cpu
```

Сначала нужно понять форматы, в которых хранятся эти облака точек, и для этого нужно посмотреть на mesh cloud.

**Почему?**

- `point-cloud-utils` поддерживает чтение распространённых форматов мешей (PLY, STL, OFF, OBJ, 3DS, VRML 2.0, X3D, COLLADA).
- Если это можно импортировать в [MeshLab](https://github.com/cnr-isti-vclab/meshlab), мы можем это прочитать! (из их readme)

Тип файла выводится из его расширения. Некоторые из поддерживаемых расширений:

** PLY (Polygon File Format) **

- Простой объект PLY состоит из набора элементов для представления объекта. Он состоит из списка (x,y,z)-троек вершин и списка граней, которые на самом деле являются индексами в списке вершин.
- Вершины и грани — два примера элементов, и большую часть файла PLY составляют именно эти два элемента.
- Можно также создавать новые свойства и прикреплять их к элементам объекта, но добавлять их нужно так, чтобы старые программы не ломались, когда встречаются эти новые свойства.

** STL (Standard Tessellation Language) **

- Этот формат аппроксимирует поверхности твёрдой модели треугольниками.
- Эти треугольники также называют фасетами: каждый фасет описывается перпендикулярным направлением и тремя точками, представляющими вершины треугольника.
- Однако в этих файлах нет описания цвета и текстуры.

** OFF (Object File Format) **

- Файлы Object File Format (.OFF) используют, чтобы представлять геометрию модели, задавая полигоны поверхности модели. Полигоны могут иметь любое число вершин.
- Формат поддерживает ASCII-текстовые версии объектов для обмена и бинарные версии для эффективности чтения и записи
- Его также называют форматом .obj.

** 3DS (3D Studio) **

- Файл с расширением .3ds представляет формат меша 3D Studio, который использует Autodesk 3D Studio.
- Формат 3DS использует бинарную структуру файла, что даёт более быстрые и меньшие файлы по сравнению с текстовыми форматами; данные организованы в чанки внутри файла.
- Эти чанки хранят информацию о формах, освещении и точке обзора, которые вместе представляют трёхмерную сцену.

** X3D (Extensible 3D Graphics) **

- X3D — основанный на XML формат 3D-графики для представления 3D-информации. Это модульный стандарт, определённый несколькими спецификациями ISO.
- Формат поддерживает векторную и растровую графику, прозрачность, эффекты освещения и настройки анимации, включая вращения, затухания и покачивания.
- Преимущество X3D — кодирование информации о цвете (в отличие от STL), которую используют при печати модели на цветном 3D-принтере.

** DAE (Digital Asset Exchange) **

- Это XML-схема с открытым стандартом, на основе которой строят файлы DAE.
- Этот формат основан на XML-схеме COLLADA (COLLAborative Design Activity) — открытом стандарте XML-схемы для обмена цифровыми активами между графическими приложениями.
- Главный плюс формата — совместимость на нескольких платформах.
- Файлы COLLADA не ограничены одной программой или производителем. Вместо этого они предлагают стандартный способ хранить 3D-активы.
