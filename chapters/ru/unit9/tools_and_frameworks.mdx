# Инструменты и фреймворки оптимизации моделей

## Набор инструментов оптимизации моделей TensorFlow (TMO)

### Обзор

TensorFlow Model Optimization Toolkit — набор инструментов для оптимизации моделей машинного обучения для развёртывания. 
Инструмент посттренировочного квантования TensorFlow Lite позволяет пользователям преобразовать веса в 8-битную точность, что уменьшает размер обученной модели примерно в 4 раза. 
Инструменты также включают API для прунинга (обрезания весов) и квантования во время обучения, если посттренировочного квантования недостаточно.
Это помогает пользователям снизить задержку и стоимость инференса, развёртывать модели на edge-устройствах с ограниченными ресурсами и оптимизировать выполнение для существующей аппаратуры или новых специализированных ускорителей.

### Руководство по установке

Tensorflow Model Optimization Toolkit доступен как pip-пакет `tensorflow-model-optimization`. Чтобы установить пакет, выполните следующую команду:
```
pip install -U tensorflow-model-optimization
```

## PyTorch Quantization

### Обзор

Для оптимизации модели PyTorch поддерживает квантование INT8 по сравнению с типичными моделями FP32, что приводит к уменьшению размера модели в 4 раза и снижению требований к пропускной способности памяти в 4 раза. 
PyTorch поддерживает несколько подходов к квантованию модели глубокого обучения:
1. Модель обучают в FP32, а затем преобразуют в INT8. 
2. Quantization aware training, где модели учитывают ошибки квантования и в прямом, и в обратном проходе, используя модули fake-quantization. 
3. Представление квантованных тензоров и выполнение операций с ними. Их можно использовать, чтобы напрямую строить модели, которые выполняют все или часть вычислений в более низкой точности. 

Подробнее о квантовании в PyTorch см. [здесь](https://pytorch.org/docs/stable/quantization.html)

### Руководство по установке

Квантование PyTorch доступно как API в пакете PyTorch. Чтобы использовать его, просто установите PyTorch и импортируйте API квантования следующим образом: 
```
pip install torch
import torch.quantization
```

## ONNX Runtime

### Обзор

ONNX Runtime — кроссплатформенный ускоритель моделей машинного обучения с гибким интерфейсом для интеграции аппаратно-специфичных библиотек. 
ONNX Runtime можно использовать с моделями из PyTorch, Tensorflow/Keras, TFLite, scikit-learn и других фреймворков.
Преимущества использования ONNX Runtime для инференса таковы:
- Улучшить производительность инференса для широкого спектра моделей ML.
- Запускать на разной аппаратуре и операционных системах.
- Обучать на Python, но развёртывать в приложение на C#/C++/Java.
- Обучать и выполнять инференс с моделями, созданными в разных фреймворках.

Подробнее об ONNX Runtime см. [здесь](https://onnxruntime.ai/docs/).

### Руководство по установке

У ONNX Runtime 2 python-пакета, и в любой одной среде должен быть установлен только один из них. 
Используйте GPU-пакет, если хотите использовать ONNX Runtime с поддержкой GPU.
Python-пакет ONNX Runtime доступен как pip-пакет. Чтобы установить пакет, выполните следующую команду:
```
pip install onnxruntime
```

Для GPU-версии выполните следующую команду:
```
pip install onnxruntime-gpu
```

## TensorRT

### Обзор

NVIDIA® TensorRT™ — это SDK для оптимизации обученных моделей глубокого обучения, чтобы обеспечить высокопроизводительный инференс. 
TensorRT содержит оптимизатор инференса глубокого обучения для обученных моделей и runtime для выполнения.
После того как пользователь обучил модель глубокого обучения в выбранном фреймворке, TensorRT позволяет запускать её с более высокой пропускной способностью и меньшей задержкой.

### Руководство по установке

TensorRT доступен как pip-пакет `tensorrt`. Чтобы установить пакет, выполните следующую команду:
```
pip install tensorrt
```
другие методы установки см. [здесь](https://docs.nvidia.com/deeplearning/tensorrt/quick-start-guide/index.html#install).

### Практическое руководство

Практическое руководство по использованию TensorRT см. в этом [ноутбуке](https://github.com/huggingface/computer-vision-course/blob/main/notebooks/Unit%209%20-%20Model%20Optimization/tensorrt.ipynb)

## OpenVINO

### Обзор

Инструментарий OpenVINO™ позволяет пользователю оптимизировать модель глубокого обучения почти из любого фреймворка и развернуть её с лучшим в классе качеством на ряде процессоров Intel® и других аппаратных платформах.
Преимущества использования OpenVINO включают:
- напрямую связываться с OpenVINO Runtime, чтобы выполнять инференс локально, или использовать OpenVINO Model Server, чтобы обслуживать инференс модели с отдельного сервера или внутри среды Kubernetes
- Написать приложение один раз, развернуть его где угодно на предпочитаемом устройстве, языке и ОС
- имеет минимальные внешние зависимости
- Снижает задержку первого инференса, используя CPU для начального инференса, а затем переключаясь на другое устройство, как только модель скомпилирована и загружена в память

### Руководство по установке

Openvino доступен как pip-пакет `openvino`. Чтобы установить пакет, выполните следующую команду:
```
pip install openvino
```

Другие методы установки см. [здесь](https://docs.openvino.ai/2023.2/openvino_docs_install_guides_overview.html?VERSION=v_2023_2_0&OP_SYSTEM=LINUX&DISTRIBUTION=ARCHIVE).

## Optimum

### Обзор

Optimum служит расширением [Transformers](https://huggingface.co/docs/transformers), предлагая набор инструментов, разработанных для оптимизации производительности при обучении и 
запуске моделей на конкретной аппаратуре, обеспечивая максимальную эффективность. В быстро меняющемся ландшафте ИИ специализированная аппаратура и уникальные оптимизации продолжают регулярно появляться. 
Optimum даёт разработчикам возможность бесшовно использовать эти разнообразные платформы, сохраняя простоту использования, присущую Transformers. 
Платформы, поддерживаемые Optimum на данный момент:
1. [Habana](https://huggingface.co/docs/optimum/habana/index) 
2. [Intel](https://huggingface.co/docs/optimum/intel/index)
3. [Nvidia](https://github.com/huggingface/optimum-nvidia)
4. [AWS Trainium and Inferentia](https://huggingface.co/docs/optimum-neuron/index)
5. [AMD](https://huggingface.co/docs/optimum/amd/index)
8. [FuriosaAI](https://huggingface.co/docs/optimum/furiosa/index)
9. [ONNX Runtime](https://huggingface.co/docs/optimum/onnxruntime/overview)
10. [BetterTransformer](https://huggingface.co/docs/optimum/bettertransformer/overview)

### Руководство по установке

Optimum доступен как pip-пакет `optimum`. Чтобы установить пакет, выполните следующую команду:
```
pip install optimum
``` 

Установку функций, специфичных для ускорителей, см. [здесь](https://huggingface.co/docs/optimum/installation).

## EdgeTPU

### Обзор

Edge TPU — это специализированная ASIC Google, разработанная для запуска ИИ на edge. Она даёт высокую производительность в небольшом физическом и энергетическом контуре, позволяя развёртывать высокоточный ИИ на edge.
Преимущества использования EdgeTPU включают:
- Дополняет Cloud TPU и сервисы Google Cloud, предоставляя сквозную инфраструктуру «облако–edge», аппаратуру + ПО для развёртывания решений на основе ИИ
- Высокая производительность в небольшом физическом и энергетическом контуре
- Объединяет заказную аппаратуру, открытое ПО и современные алгоритмы ИИ, чтобы предоставлять качественные, простые в развёртывании ИИ-решения для edge

Подробнее об EdgeTPU см. [здесь](https://cloud.google.com/edge-tpu)

Руководство по установке и использованию EdgeTPU см. в этом [ноутбуке](https://github.com/huggingface/computer-vision-course/blob/main/notebooks/Unit%209%20-%20Model%20Optimization/edge_tpu.ipynb)
